# Provenance of the shared core

`core/` is canonical for the Treatable apps and is a second copy of reviewed, security-critical code from the Chrome extension (final-plan.md amendment R3). This file records, for every ported file and function, where it came from, what changed, and why. Converging the extension onto `core/` is a later task that needs coordination with the extension's maintainers; `extension/` is not edited here.

- Source commit: `48c569e6ade1803730384870d5cd1cffbf895676` (`48c569e`, branch `codex/treatable-mvp`, "fix: restrict side panel to ClinicalTrials.gov tabs").
- Reviewed state: `extension/SECURITY_REVIEW.md` (review of source `29f126b`, recorded at `48c569e`).
- Ported by task A1a on 2026-10-24. Screening, the offline ZIP lookup, and the outbound transport gate were ported by task A1b on 2026-10-24; their sources (including the scaffold, which the drift check pins the same way) are in the tables below.
- Ported by task A1a on 2026-10-24; revised the same day to fix the A1a critic findings (send capability, request pins, record index, canonical Agents input, receipt clearing rules).
- Drift check: `node scripts/drift-check.mjs` compares each source below (by git blob ID at `48c569e`) with a target commit or the working tree and exits non-zero on any change. On 2026-10-24 it reported no drift against this branch. Against `codex/treatable-mvp` it reported no drift at `4281bef`, but that branch has moved: a read-only run of `node scripts/drift-check.mjs --target codex/treatable-mvp` on 2026-10-24 (Node v26.11.0, target `d0f11d0`, 57 commits after `48c569e`) exits 1 with 12 changed files: `extension/native/real.mjs`, `extension/shared/demo-contract.mjs`, `extension/shared/demo-contract.d.mts`, `extension/shared/demo-fixtures.mjs`, `extension/native/host.mjs`, `extension/native/core.mjs`, `extension/src/validation.ts`, `extension/src/core.ts`, `extension/native/transport.mjs`, `extension/native/provider.mjs`, `extension/native/test/core.test.mjs`, and `extension/tests/core.test.ts`. For the sources that A1b ported, the diffs were read: `extension/src/core.ts` adds `trialUrl`, narrows `safeWebUrl` to HTTPS, and removes the local-model explanation helpers, none of which touches `resolveZip` or `nearestSite`; `extension/tests/core.test.ts` drops the explanation tests and leaves the ZIP cases as they were; `extension/src/validation.ts` removes the local-model request helpers and leaves `boundedText` unchanged; `scaffold/lib/eligibility/hardFilters.ts`, the ZIP table, and the scaffold test are unchanged; `extension/native/transport.mjs` adds `servername: 'api.openai.com'` and `minVersion: 'TLSv1.2'` to its `https.request` options. That last change belongs to the host transport, not to the gate, and `node/ports.node.ts` (`createNodeTransport`) does not have either option yet; carrying them over, with a test, is on the pre-CP2 re-base list. The other changed files belong to the A1a, A4, and A6a ports and are reviewed at that re-base.

## Not ported

- Chrome-only code: `validateOrigin`, `EXTENSION_ID`, `HOST_NAME`, native messaging manifests, the installer (`install.mjs`). The import-graph test bans these names in `core/src`.
- macOS Keychain access (`credentials.mjs`, `credential.swift`): replaced by the `credential.request` protocol; each platform stores the key in its own credential store (task A6b and the platform tasks).
- The 2,000-study snapshot, public catalog, demo fixtures, and BM25 pipeline (live ClinicalTrials.gov search replaces them).
- Provider runners (`provider.mjs`): task A4. The outbound rules of `transport.mjs` (path allowlist, Bearer key, `OpenAI-Beta` on Agents paths, 96 KiB body cap) are now enforced by the core's send capability (`src/outbound.ts`) with exact method and path pairs; task A1b adds a transport gate around the port. The Decisions retry rule of docs/apps/openai-contracts.md section 10.6 is owned by the send capability, not by the provider pipeline. Both files are listed in the drift check because they are security-critical.
- The scaffold's patient-facing explanation pipeline (warnings, note strings, call scripts, `scoreStudyMatches` narration): task A5 owns user-facing language. The scaffold's `openTo` toggles and expanded-access visibility are a host preference, not a core rule.
